# Telegram-бот «Шпион»

Небольшой бот для игры компанией в одной комнате. Бот управляет комнатами, хранит банк слов и рассылает каждому игроку его роль в личные сообщения. Само обсуждение и угадывание проходят устно.

## Что реализовано

- Создание комнаты с названием и паролем.
- Список всех комнат для выбора; можно вступать даже в уже начавшуюся игру.
- Один пользователь может состоять только в одной комнате одновременно.
- Создатель комнаты становится её администратором.
- Новые игроки могут входить во время всех фаз игры по названию комнаты и паролю.
- Любой участник может выйти во время игры кнопкой «ВЫЙТИ ИЗ ИГРЫ»; если выходит создатель, права передаются другому участнику.
- Комнаты автоматически удаляются через 24 часа без активности.
- При сборе слов бот сразу просит каждого участника отправить слово, затем предлагает подтвердить его или изменить.
- Имена участников в панели являются ссылками на их Telegram-профили; для неинформативных имён используется username.
- Сбор одного слова от каждого игрока. Игрок может изменить своё слово до начала раунда.
- Администратор видит, кто отправил слово, а кто нет. Сами слова в списке готовности не показываются.
- Администратор может начать первый раунд, даже если не все прислали слова, но хотя бы одно слово в банке должно быть.
- Для игры требуется минимум три игрока.
- Бот случайно выбирает неиспользованное слово, затем выбирает шпиона и первого говорящего.
- Роли и слово отправляются каждому игроку отдельным личным сообщением.
- После раунда администратор запускает следующий. Если в банке осталось три слова или меньше, начинается пополнение: все участники должны добавить по слову, а старые неиспользованные слова сохраняются.
- Пароли комнат хранятся в SQLite только в виде PBKDF2-хеша с солью; бот также пытается удалить сообщения с введёнными паролями из личного чата.
- Данные переживают перезапуск бота и сервера.

## Два игровых ограничения

1. **Автор выбранного слова не может стать шпионом.** При выборе шпиона бот исключает автора выбранного слова из списка кандидатов.
2. **Шпион не может начать раунд.** Первый говорящий выбирается случайно только среди игроков, которые не стали шпионом.

Если слово в банке осталось от игрока, который уже вышел из комнаты, его ID больше не входит в список участников, поэтому он никого из текущих игроков не исключает.

## Перед запуском

- Python 3.11 или новее.
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather).
- Каждый участник должен хотя бы один раз открыть бота и нажать `/start`: Telegram не позволяет боту первым написать пользователю в личку.

Бот работает через long polling. — сервер сам устанавливает исходящее HTTPS-соединение с Telegram.

## Быстрая проверка локально

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env
```

В `.env` укажи токен:

```dotenv
BOT_TOKEN=токен_от_BotFather
DB_PATH=./data/spybot.sqlite3
LOG_LEVEL=INFO
```

Затем запусти:

```bash
set -a
source .env
set +a
python bot.py
```

Открой бота в Telegram и отправь `/start`.

## Установка на Ubuntu 24.04

Ниже пример для стандартного пользователя `ubuntu`. Архив `spybot-bot.zip` нужно предварительно загрузить на сервер, например с локального компьютера:

```powershell
scp .\spybot-bot.zip ubuntu@АДРЕС_СЕРВЕРА:/home/ubuntu/
```

Подключись по SSH и выполни:

### 1. Установить системные пакеты и распаковать проект

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip unzip
sudo mkdir -p /opt/spybot
sudo unzip /home/ubuntu/spybot-bot.zip -d /opt/spybot
```

### 2. Создать отдельного системного пользователя

```bash
sudo adduser --system --group --home /opt/spybot --no-create-home spybot
sudo mkdir -p /opt/spybot/data
sudo chown -R spybot:spybot /opt/spybot
```

### 3. Создать виртуальное окружение и установить зависимости

```bash
sudo -u spybot python3 -m venv /opt/spybot/venv
sudo -u spybot /opt/spybot/venv/bin/pip install --upgrade pip
sudo -u spybot /opt/spybot/venv/bin/pip install -r /opt/spybot/requirements.txt
sudo apt update && sudo apt install -y nano
```

### 4. Добавить токен бота

```bash
sudo -u spybot cp /opt/spybot/.env.example /opt/spybot/.env
sudo nano /opt/spybot/.env
```

Вставь токен от BotFather. Проверь, что путь к базе выглядит так:

```dotenv
BOT_TOKEN=твой_реальный_токен
DB_PATH=/opt/spybot/data/spybot.sqlite3
LOG_LEVEL=INFO
```

Затем:

```bash
sudo chown spybot:spybot /opt/spybot/.env
sudo chmod 600 /opt/spybot/.env
```

### 5. Проверить запуск вручную

```bash
sudo -u spybot bash -lc 'cd /opt/spybot && set -a && source .env && set +a && ./venv/bin/python bot.py'
```

Если в логе появилась строка `Starting @имя_бота`, бот запустился. Проверь `/start` в Telegram. Остановить тестовый запуск можно `Ctrl+C`.

### 6. Настроить автозапуск через systemd

Создай unit-файл:

```bash
sudo nano /etc/systemd/system/spybot.service
```

Вставь:

```ini
[Unit]
Description=Telegram Spy Game Bot
Wants=network-online.target
After=network-online.target

[Service]
Type=simple
User=spybot
Group=spybot
WorkingDirectory=/opt/spybot
EnvironmentFile=/opt/spybot/.env
ExecStart=/opt/spybot/venv/bin/python /opt/spybot/bot.py
Restart=on-failure
RestartSec=5

# Небольшое усиление изоляции процесса
NoNewPrivileges=true
PrivateTmp=true
UMask=0077
ProtectSystem=strict
ProtectHome=true
ReadWritePaths=/opt/spybot/data

[Install]
WantedBy=multi-user.target
```

Активируй сервис:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now spybot
sudo systemctl status spybot
```

Посмотреть лог в реальном времени:

```bash
sudo journalctl -u spybot -f
```

Перезапуск после изменения кода или `.env`:

```bash
sudo systemctl restart spybot
```

Остановка:

```bash
sudo systemctl stop spybot
```

## Как играть

1. Каждый участник открывает бота и нажимает `/start`.
2. Один игрок создаёт комнату, задаёт название и пароль.
3. Остальные выбирают комнату из списка и вводят пароль.
4. Когда все собрались, создатель нажимает **«Начать сбор слов»**.
5. Каждый нажимает **«Отправить / изменить слово»** и присылает одно слово. Бот не публикует его в комнате.
6. Создатель нажимает **«Проверить готовность»**, чтобы увидеть список отправивших и не отправивших.
7. Создатель нажимает **«Начать раунд»**. Если в комнате минимум три игрока и есть хотя бы одно слово, раунд начнётся, даже если кто-то не успел придумать слово.
8. Каждый получает роль в личку. Бот также указывает, кто начинает.
9. После устного обсуждения создатель нажимает **«Следующий раунд»**.
10. Когда осталось не больше трёх слов, бот включает пополнение банка. Каждый должен добавить новое слово, прежде чем администратор сможет запустить следующий раунд.

## Полезные команды

- `/start` — открыть главное меню.
- `/menu` — показать меню.
- `/cancel` — отменить ввод названия, пароля или слова.

## Где хранятся данные

По умолчанию SQLite-база находится в `data/spybot.sqlite3` локально или `/opt/spybot/data/spybot.sqlite3` на сервере. В ней хранятся комнаты, участники и банк слов. Удаление комнаты удаляет её слова и участников.

Для простого резервного копирования останови сервис и скопируй базу:

```bash
sudo systemctl stop spybot
sudo cp /opt/spybot/data/spybot.sqlite3 /opt/spybot/data/spybot-backup.sqlite3
sudo systemctl start spybot
```

Не публикуй `.env`, токен бота или файл SQLite с данными комнаты.

## Ограничения текущей версии

- Игра рассчитана на компанию, которая находится в одном помещении: бот не проводит голосование и не определяет победителя.
- Если бот не смог написать хотя бы одному участнику в личку, раунд отменяется, а уже отправившимся сообщениям приходит уведомление об отмене. Такой игрок должен открыть бота и нажать `/start` (или разблокировать бота), после чего можно повторить запуск.
